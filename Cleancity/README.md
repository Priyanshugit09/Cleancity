# CleanCity - Privacy-First Garbage Complaint Management System

## Overview
CleanCity is a Flask-based web application that allows citizens to report garbage-related issues while protecting their privacy. Users can register, log in, submit complaints with images, and track complaint status. Administrators can manage complaints and update their status.

## Features

- User Registration & Login
- Secure Password Hashing
- Complaint Submission
- Image Upload
- Complaint History
- Admin Dashboard
- Status Updates (Pending, In Progress, Resolved)
- SQLite Database

## Technologies Used
